## 2026-10-08｜3D 動作小實驗

- Luna 已授權製作會動的 3D，採 Three.js 0.180.0；本機依賴與 MIT LICENSE 放在 vendor/。
- 操作：拖曳鏡頭、滾輪縮放，選陸地／水下／雨季示範；可暫停、重播、調速度或拖動作位置。
- 在 repo 根目錄執行 `python3 -m http.server 8765 --bind 127.0.0.1`，開啟 <http://127.0.0.1:8765/m2-species/>，不能直接雙擊 HTML 載入模組。
- index.html 建操作介面。sketch.js 第 1 段建場景與鏡頭，第 2 段建展示地面與河流，第 3 段建身體，後段以時間改變姿勢與位置。
- 研究選型：Three.js 能控制 3D 部位與鏡頭，p5.js 較貼近課程入門；本輪選 Three.js。來源：[場景教學](https://threejs.org/manual/pages/creating-a-scene.html)、[安裝](https://threejs.org/manual/pages/installation.html)。
- Chrome 已實際檢查渲染、場景切換、暫停、重播、動作位置及水下／換氣姿勢；JavaScript 語法檢查通過。需 Luna 親自操作確認符合想像。
- 模型與配色暫定；三個示範是預設時間軌跡，不是物理模擬或自主感知。演示縮短季節與三十分鐘換氣時間，展示尺度未映射實際森林大小或能見度。
- 未完成進食、卵、碰撞傷害。側煞、浮沉及岸邊路徑仍需細修，不宣稱完整 M2 交付或科學驗證完成。
- 下一步由 Luna 查看姿態，再逐項調整。
- AI：Codex，2026-10-08。Prompt：現在做會動的 3D。採用範圍：依 Luna 設定實作幾何模型、場景、動作軌跡與介面，未代寫本人反思或研究結論。
