# 借殼地貌 3D 模型

2026-10-15。此為重新創作的借殼地貌，舊圓胖動物保留在上層資料夾。

## 開啟與操作

在 repo 根目錄執行 `python3 -m http.server 8765 --bind 127.0.0.1`，開啟 <http://127.0.0.1:8765/m2-species/shellscape/>。

- 拖曳旋轉、滾輪縮放、右鍵平移。
- Tweakpane 面板可選動作、速度、外殼開合、雨季，展開「觀察光線」可調光、霧與自動環視。
- 底部提供暫停、開殼、重設鏡頭、圖片保存、目前姿態 GLB 匯出。
- GLB 為靜態姿態、含貼圖，沒有烘焙動作。動態牽引與膜變形在網頁程式中。
- 成品 GLB 與 PNG 已存桌面 `借殼地貌/`。GLB 不含展示台與介面。程式與貼圖本機運作，不依賴 CDN。

## 模型內容

34 組不規則碎片組成外殼，混凝土、陶片、鏽蝕金屬使用不同材質。部分附骨材與露出的細金屬。下方為多皺薄膜、放射狀管脈、儲水囊，以及連接碎片和地面的牽引絲。局部碎片沿預設路徑抓入、放出；可開殼查看內部。

造型依 Luna 選定的「借殼地貌」候選發展；本輪材質、內膜外觀與構造細節為 AI 製作提案，待 Luna 檢視，不自行當成最終生理設定。展示光線與可見距離不等於世界的真實環境數值。

## GitHub 研究與選型

| 工具 | 用途與取捨 | 本輪 |
|---|---|---|
| [Three.js](https://github.com/mrdoob/three.js) | 沿用本地 0.180.0，程式幾何可直接控制碎片與膜。較易迭代，但非手工雕刻資產。MIT | 採用 |
| [OrbitControls](https://github.com/mrdoob/three.js/blob/r180/examples/jsm/controls/OrbitControls.js) | 旋轉、縮放與平移鏡頭。MIT | 採用 |
| [Tweakpane](https://github.com/cocopon/tweakpane) | 4.0.5，無額外依賴的參數控制，提供一致的滑桿、選單、資料夾及可調色主題。MIT | 採用 |
| [GLTFExporter](https://github.com/mrdoob/three.js/blob/r180/examples/jsm/exporters/GLTFExporter.js) | 同版本匯出 glTF/GLB，可輸出目前材質與姿態。MIT | 採用 |
| [MarchingCubes](https://github.com/mrdoob/three.js/blob/dev/examples/jsm/objects/MarchingCubes.js) | 適合團塊融合，但此輪需要薄膜與獨立碎片，改用自製網格 | 研究未採用 |
| [postprocessing](https://github.com/pmndrs/postprocessing) | 可加 bloom，但增加渲染成本，本輪先靠材質與燈光展現差異。Zlib | 研究未採用 |

沒有找到並套用現成「借殼地貌」角色。採用的是開源基礎工具，生物網格、動作與主介面由本輪製作。Tweakpane 與 Three.js 授權檔隨依賴保留。

## 程式導覽

`index.html`：觀察室版面與按鈕。
`creature.js` 第 1 段：場景、鏡頭與燈光。第 2 段：材質與內膜。第 3 段：不規則外殼與動態牽引絲。第 4 段：參數面板、呼吸／搬運軌跡與匯出。

## 驗證與限制

- `node --check` 與 `git diff --check`。
- Chrome 實際渲染；操作開殼、雨季、暫停與 GLB／PNG 匯出。
- 匯出 GLB 的標頭、總長、JSON 結構與網格／材質存在性檢查通過，尚未在 Blender 匯入驗證。
- 搬運與開合是視覺軌跡，非碰撞或受力模擬。尚無自主尋找碎片、食物代謝、繁殖與傷害系統。
- 未烘焙動畫；控制面板的開殼為觀察工具，不代表永久會飛浮的殼。
- 請 Luna 實際檢視並決定採用範圍。完成此模型不等於 M2 所有交付與反思完成。
